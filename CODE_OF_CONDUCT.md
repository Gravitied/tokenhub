# Code Of Conduct

TokenHub MCP contributors and maintainers are expected to keep project spaces respectful, practical, and focused on the work.

## Expected Behavior

- Be direct without being hostile.
- Assume good intent, but correct technical issues with evidence.
- Keep discussions relevant to the project.
- Respect privacy and do not post credentials, private logs, or personal information.
- Help make issues and pull requests actionable.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing another person's private information.
- Repeated off-topic disruption.
- Deliberately submitting malicious code, credential material, or misleading security claims.

## Enforcement

Maintainers may edit or remove comments, close discussions, block accounts, or reject contributions that violate this code. Serious security or safety concerns should be reported privately using `SECURITY.md`.
